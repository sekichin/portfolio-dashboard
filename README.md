# Portfolio Dashboard

個人投資家向けに開発した、モバイルファーストの資産管理 Web アプリです。  
米国株、日本株、投資信託、金などを一つの画面で管理し、保有資産・損益・履歴・将来予測を確認できます。

> 本リポジトリはポートフォリオ閲覧用のソースコードです。実際の利用者データ、ログインキー、API キー、運用環境の認証情報は含まれていません。

## 主な機能

### 資産ダッシュボード

- 総資産、投資元本、累計損益、当日損益、年率換算リターンを表示
- 金額の表示／非表示を切り替え、選択状態を端末に保存
- 資産配分を円グラフで可視化
- 口座・商品種別による絞り込み
- ライトテーマ／ダークテーマ切り替え
- スマートフォン向けのタブ移動とレスポンシブ表示

### 保有資産管理

- 米国株、日本株、投資信託、金に対応
- 保有数量、平均取得価格、時価、累計損益を自動計算
- 保有状況を重視した表示と、相場情報を重視した表示を切り替え
- 商品名、コード、口座、取得価格、数量を手動修正可能
- 売却記録から実現損益を管理
- 保有資産の変更時に取引履歴を記録

### 持ち株のインポート／エクスポート

- 証券会社のスクリーンショットや保有明細を AI で Markdown 表に整理
- Markdown 表を貼り付けて保有資産を一括インポート
- 既存データとの差分を事前確認
- 新規追加、更新、アーカイブを区別して安全に統合
- 情報不足の項目を編集画面で強調表示
- 現在の保有資産を Markdown 形式でエクスポート

### 市場データ

- 米国株の通常取引・プレマーケット・アフターマーケット表示
- 日本株、投資信託、金、USD/JPY に対応
- 複数の取得経路と前回成功値を利用したフォールバック
- 外貨資産の円換算損益に為替変動を反映
- 投資信託は公開される基準価額を利用

### パフォーマンス分析

- 資産推移と比較指数のチャート
- 日次／週次／月次表示
- 日報、月報、年報、全期間レポート
- 期間損益、収益率、期末資産、最大ドローダウン
- 最良日／最悪日、上昇日比率、連続上昇／下落日数
- 寄与額上位／下位銘柄、為替影響を表示
- 入出金の影響を分離した期間収益率を計算

### 収益カレンダー

- 営業日ベースの損益カレンダー
- 日別の損益額、収益率、銘柄別寄与を確認
- 休場日は直近の有効な取引日を参照
- AI による日次変化の分析と再分析
- 分析結果をアカウント別・日付別に保存

### 資産目標シミュレーション

- 目標金額、目標年月、定期投資計画を設定
- 資産タイプごとに現在額・想定年率・外貨比率を設定
- 悲観／基準／楽観の三つのシナリオを計算
- 年度別の資産、累計投資額、投資収益、目標差額を表示
- 将来の資産構成、為替ストレス、目標達成時期を可視化
- AI が保有資産と計画を分析し、想定年率と目標達成確率を提示
- 目標達成に影響する要因と改善案を表示

### アカウント管理

- 個別ログインキーによるアカウント分離
- 新規アカウントに体験期間を設定
- 管理画面から 7 日、1 か月、永久利用を付与
- アカウントの一時停止、AI 機能の有効化／無効化
- アカウント削除時に関連データも削除
- AI 日次分析と資産予測に個別の一日利用上限を設定

## 設計上のポイント

- **モバイルファースト**：スマートフォンで重要な数字を素早く確認できる情報設計
- **データ分離**：保有資産、履歴、設定、AI 結果をアカウント単位で管理
- **計算と AI の分離**：金額・収益率・複利計算はプログラム側で実行し、AI は解釈と文章生成を担当
- **フォールバック設計**：一時的に相場取得が失敗しても、最後に取得できた値を保持
- **秘密情報をコードから分離**：認証情報と API キーは環境変数で管理

## ローカルでの起動

### 1. 仮想環境の作成

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. 依存関係のインストール

```bash
pip install -r requirements-local.txt
```

### 3. 環境変数の設定

必要な値だけを `.env.local` に設定します。

```env
PORTFOLIO_ADMIN_KEY=change-this-admin-key
PORTFOLIO_HOST=127.0.0.1
PORTFOLIO_PORT=8765

# クラウド保存を使用する場合
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=

# AI 機能を使用する場合
GEMINI_API_KEY=
```

### 4. サーバーの起動

```bash
python3 app.py
```

ブラウザで `http://127.0.0.1:8765` を開きます。

## データとセキュリティ

- `.env.local`、実際の保有資産、ログインキー、バックアップは Git 管理対象外です。
- 公開リポジトリにはサンプル以外の利用者データを保存しません。
- Supabase の Service Role Key と AI API Key はクライアントへ直接配布しません。
- 本番運用では HTTPS、十分に長いログインキー、アクセス制御、バックアップが必要です。
- 市場データは各提供元の公開情報に依存し、取引執行を目的としたリアルタイム配信ではありません。

本アプリが表示する分析や将来予測は参考情報であり、投資助言ではありません。価格、為替、損益、税務上の数値は利用前に証券会社の正式な情報と照合してください。
